# Unforgettable Memories

A cinematic digital memory gallery for preserving and sharing unforgettable moments with friends.

## Features

- Custom memory titles
- Friend names
- Year / month / date timeline
- Multiple photos per memory
- Multiple videos per memory
- Automatic collage-style gallery
- Memory quotes
- Full-screen media viewer
- Public viewing
- Friend submissions
- Admin approval
- Password-protected Keeper area
- Upload limits
- MIME type restrictions
- SQLite database
- Secure sessions
- Login rate limiting
- Security headers
- Responsive mobile design
- Lazy-loaded images
